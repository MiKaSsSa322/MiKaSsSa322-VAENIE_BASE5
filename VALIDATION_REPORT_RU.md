# Отчёт повторной проверки Frontier: Military Installations 1.0.5

Дата: 26.11.2026

## Исправлено

- `/nearestbuilding` больше не передаёт `TagKey` напрямую в метод поиска: команда сначала получает `HolderSet.Named<Structure>` из реестра структур, затем передаёт корректный тип в `findNearestMapStructure`.
- Исправлен тип результата API поиска: `Pair<BlockPos, Holder<Structure>>`.
- Добавлена проверка пустого/не найденного тега с понятным сообщением, вместо потенциальной ошибки.
- Оба варианта команды (`/nearestbuilding` и `/nearest_building`) теперь имеют одинаковые подкоманды и автодополнение.
- Обновлена версия проекта до 1.0.5.
- Усилен офлайн-валидатор: проверяет теги каждой структуры, общий тег, параметры spacing/separation и salt.
- Обновлена русская документация и отчёт проверки.

## Проверки, выполненные здесь

- Все 6 gzip/NBT-шаблонов читаются; размеры, палитры, индексы, координаты и отсутствие повторяющихся координат проверены.
- Все JSON ресурсов корректны; ссылки structure → template pool → NBT проверены.
- Параметры размещения проверены (separation меньше spacing).
- Проверены индивидуальные и общий теги структур.
- Сигнатуры API поиска сверены с документацией Forge/Minecraft 1.20.1.

## Не подтверждено

Настоящая Gradle/Forge сборка и запуск Minecraft не выполнены: в среде нет Gradle и доступа к скачиванию зависимостей. Поэтому архив остаётся исходным проектом; я не выдаю его за собранный JAR. Для окончательной проверки в игре нужен запуск на Forge 47.2.x / Minecraft 1.20.1 и тест команды в новом мире.
